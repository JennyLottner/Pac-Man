# Pac-Man

A simple implementation of the classic Pac-Man game. Controlled by the arrow keys, Pac-Man must consume all the dots inside an enclosed maze while avoiding colorful ghosts. Special items like broccoli and cookies add additional gameplay elements.

## Features
- **Arrow Key Controls**: Move Pac-Man using the arrow keys.
- **Dot Collection**: Consume all dots in the maze to win.
- **Ghosts**: Avoid colorful ghosts.
- **Regular Movement**: Ghosts move at regular intervals regardless of user input.
- **Broccoli (🥦)**: Temporarily turns ghosts blue, allowing Pac-Man to eat them. Ghosts return to their original color after a short period.
- **Cookies (🍪)**: Grant an additional points when eaten.
- **Audio Feedback**: Plays sound effects on specific events such as winning or losing.

## Technologies used
- HTML5
- CSS3
- Vanilla JavaScript

This project was my first vanilla JavaScript application. Through building it, I learned how to:
- **Keyboard Event Handling**: Implemented listening to arrow key events to control Pac-Man’s movement.
- **Animation and Timing**: Managed the movement of ghosts and other game elements using updates at regular intervals.
- **Audio Integration**: Added audio files that activate in response to user actions, enhancing the game experience.
- **Interactive Screen Rendering**: Created a usable application with visual elements displayed on the screen, moving beyond console-based output.

## Installation
You can view the project live [here](https://jennylottner.github.io/Pac-Man/)

Alternatively, if you'd like to run it locally:
1. Clone the repository: `git clone https://github.com/JennyLottner/Pac-Man.git`
2. Navigate to the project folder and open the `index.html` file in your browser.

## Usage
1. Use the arrow keys to control Pac-Man.
2. Navigate through the maze to eat all the dots.
3. Avoid ghosts and eat broccoli (🥦) and cookies (🍪) for bonuses.
4. The game ends when Pac-Man eats all the dots or runs into a ghost.
